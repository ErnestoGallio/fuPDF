# Segnalazioni di sicurezza

## Canale riservato

Il canale previsto per il repository pubblico è **Security → Advisories →
Report a vulnerability** su GitHub. Il canale sarà disponibile dopo la
creazione del repository pubblico e l'attivazione di *Private vulnerability
reporting*. Se il pulsante è assente, attendi l'attivazione prima di inviare i
dettagli. Tieni le vulnerabilità fuori dalle issue, dalle pull request e dalle
discussioni pubbliche. [Configurazione del canale riservato su GitHub](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository)

## Contenuto della segnalazione

- Versione di fuPDF e versione di Windows.
- Comportamento osservato, impatto e condizioni necessarie per riprodurlo.
- Passi riproducibili con una fixture sintetica e, se utili, estratti di log
  ripuliti.

Evita PDF riservati, dati personali e credenziali, anche nel canale
riservato. Indica se il problema coinvolge il flusso della revisione IA,
il salvataggio locale o un componente incluso nel pacchetto Windows.
